Runnable examples

These links point to real files in the repository’s examples/ directory.

export POLONIO_STORAGE_PATH="$PWD/.polonio-storage"
export POLONIO_SESSION_SECRET="development-secret-change-me"
mkdir -p "$POLONIO_STORAGE_PATH"
./build/polonio serve --root ./examples --port 8080

Open http://127.0.0.1:8080/hello. Server filesystem routing also makes /hello.pol work. Storage-dependent examples require the environment above.

  • hello.pol — variables, interpolation, loop, and inline echo.
  • forms.pol — query parameters, URL-encoded POST, CSRF, and escaped form output.
  • json.pol — explicit request_json() handling.
  • session.pol — signed session counter.
  • upload.pol — multipart _FILES and upload_save.
  • download.pol — send_file (create a storage downloads/example.txt first).
  • storage.pol — sandboxed directory/file operations.
  • sqlite.pol — SQLite table, parameterized insert, query, close.
  • mail.pol — file-mode send_mail.
  • 404.pol — custom development-server missing-page template.
  • assets/style.css — shared minimal styling.

These examples use canonical names html_escape and to_string. Their aliases htmlspecialchars and tostring behave identically.
