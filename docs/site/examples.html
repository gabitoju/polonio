Runnable Examples

Small filesystem routes for the official Polonio Reference Distribution.

These are real files in examples/. They demonstrate Template Runtime features and, where noted, the Web and Data Runtimes. A Language Core or template-only implementation is not required to provide the Web/Data examples.

export POLONIO_STORAGE_PATH="$PWD/.polonio-storage"
export POLONIO_SESSION_SECRET="development-secret-change-me"
mkdir -p "$POLONIO_STORAGE_PATH"
./build/polonio serve --root ./examples --port 8080

Open http://127.0.0.1:8080/ or /hello. Filesystem routing also accepts /hello.pol. Storage-dependent examples require the environment above.

Language and Template Runtime

  • hello.pol — variables, interpolation, a loop, and inline echo.
  • 404.pol — custom missing-page template for the development-server adapter.
  • assets/style.css — shared minimal styling.

Web Runtime

  • forms.pol — query parameters, URL-encoded POST, CSRF, and escaped form output.
  • json.pol — explicit request_json() handling.
  • session.pol — signed session counter.
  • upload.pol — multipart _FILES and upload_save.
  • download.pol — send_file; create downloads/example.txt in storage first.
  • mail.pol — file-mode send_mail, not SMTP delivery.

Data Runtime

  • storage.pol — sandboxed directory/file operations.
  • sqlite.pol — SQLite table creation, parameterized insert, query, and close.

Examples use the canonical names html_escape and to_string. The supported compatibility aliases htmlspecialchars and tostring behave identically, but are not primary example syntax. See Builtins for aliases and layers, and Runtime for execution requirements.
